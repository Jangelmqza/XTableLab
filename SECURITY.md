# Política de Seguridad (Security Policy)

Actualmente se brindan actualizaciones de seguridad para la última versión publicada:

| Versión | Soportada |
| ------- | --------- |
| 1.2.x   | ✅ Sí     |
| < 1.2.0 | ❌ No     |

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad en **XTableLab**, por favor **no abras un Issue público**.
En su lugar, repórtalo de manera privada a través de la pestaña **Security → Report a vulnerability** (Private Vulnerability Reporting) de este repositorio en GitHub.

Revisaremos el reporte a la brevedad y publicaremos un parche antes de divulgar los detalles.
